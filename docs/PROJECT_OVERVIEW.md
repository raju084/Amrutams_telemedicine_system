## 1. What is this project?

Amrutam Telemedicine Backend is the server-side engine powering the Amrutam Pharmaceuticals online doctor consultation platform.

Think of it as the brain behind the app:
- When a patient books a doctor, this backend handles it.
- When a doctor writes a prescription, this backend stores and cryptographically signs it.
- When a payment is made, this backend processes it securely via Razorpay.
- Every action is logged in a tamper-proof audit trail for DISHA compliance.
